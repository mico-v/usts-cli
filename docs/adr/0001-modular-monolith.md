# ADR-0001：采用模块化单体与兼容 façade

状态：Accepted

## 决策

继续使用 TypeScript 模块化单体。保留 `JwglClient` 作为兼容 façade，逐步抽取领域、配置、HTTP、会话、DTO 解析和端点能力。

## 原因

项目是单用户 CLI，远端 I/O 是主要瓶颈。微服务或语言重写不会改善核心问题，反而增加部署和协议迁移成本。渐进式 façade 可保持现有 CLI 兼容并降低一次性重构风险。

## 后果

- 新代码必须遵循固定依赖方向。
- façade 暂时存在，但不得继续吸收通用基础设施职责。
- 使用特征测试和契约夹具保障迁移等价性。
