# ADR-0003：会话迁移到用户状态目录

状态：Accepted

## 决策

会话使用跨平台用户状态目录、版本化格式、完整 Cookie 属性、`0700/0600` 权限和原子保存。旧版 cwd `.session.json` 仅作为兼容迁移来源。

## 原因

当前工作目录可能属于共享仓库或临时目录，默认 `0644` 会暴露登录 Cookie，且简单 `Map` 丢失 Cookie 的域、路径和过期规则。

## 后果

- 从任意目录运行 CLI 都使用同一用户会话。
- 会话与配置 origin 绑定，防止跨主机复用。
- 抓包工具同步使用安全状态目录。

## 修订

「旧版 cwd `.session.json` 仅作为兼容迁移来源」这一条已被 [ADR-0004](0004-retire-legacy-cwd-session.md) 修订：该隐式读取已退役，只在启动时检测并提示清理。
